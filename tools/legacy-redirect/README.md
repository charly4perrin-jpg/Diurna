# Ancienne adresse de Diurna

Ces deux fichiers forment tout le site du dépôt `charly4perrin-jpg/trois-phrases` (recréé vide après
le renommage en `diurna`). GitHub Pages sert `index.html` pour la racine et `404.html` pour toute
autre adresse : les deux renvoient vers la même page sur la nouvelle adresse, chemin et ancre compris.

Quand le domaine définitif sera actif, remplacer `https://charly4perrin-jpg.github.io/diurna` par
`https://diurna.world` dans les deux fichiers (variable `NEW`, lien canonique, rafraîchissement).
